🔌 Connection Events /user

connected RECEIVE

Received immediately after successful connection and authentication.

Sample Response:
{
  "userId": "697603eaafa341b7c814e5f9",
  "name": "Harsha Vardhan",
  "message": "Connected successfully"
}
member:offline BROADCAST

Broadcast to group members when a member disconnects.

Sample Response:
{
  "userId": "697603eaafa341b7c814e5f9",
  "name": "Harsha Vardhan",
  "reason": "transport close"
}
error RECEIVE

Received when any WebSocket operation fails.

Sample Response:
{
  "event": "location:update",
  "message": "latitude and longitude are required"
}

📍 Location Events /user

location:update EMIT

Send your current location. Broadcasts to group members and admins.

Payload:
{
  "latitude": 12.9716,
  "longitude": 77.5946,
  "altitude": 920,
  "speed": 5.2,
  "accuracy": 10,
  "heading": 180,
  "battery": 85
}
location:updated RECEIVE

Confirmation that your location was saved successfully.

Sample Response:
{
  "success": true,
  "timestamp": "2026-02-01T10:30:00.000Z"
}
location:broadcast BROADCAST

Received when a group member updates their location.

Sample Response:
{
  "userId": "697603eaafa341b7c814e5f9",
  "name": "Harsha Vardhan",
  "profilePicture": "https://example.com/photo.jpg",
  "latitude": 12.9716,
  "longitude": 77.5946,
  "altitude": 920,
  "speed": 5.2,
  "accuracy": 10,
  "heading": 180,
  "battery": 85,
  "timestamp": "2026-02-01T10:30:00.000Z",
  "groupId": "6789abcdef1234567890abcd"
}
location:get-group EMIT

Request all group members' last known locations.

Payload:
{
  "groupId": "6789abcdef1234567890abcd"
}

🚨 SOS/Alert Events /user

sos:trigger EMIT

Trigger an emergency SOS alert. Notifies group members, emergency contacts, and all admins.

Payload:
{
  "latitude": 12.9716,
  "longitude": 77.5946,
  "message": "I need help immediately!"
}
sos:confirmed RECEIVE

Confirmation that SOS was sent successfully.

Sample Response:
{
  "alertId": "67a1b2c3d4e5f67890123456",
  "message": "SOS sent successfully",
  "timestamp": "2026-02-01T10:30:00.000Z"
}
sos:alert BROADCAST

Received by group members when someone triggers SOS.

Sample Response:
{
  "alertId": "67a1b2c3d4e5f67890123456",
  "user": {
