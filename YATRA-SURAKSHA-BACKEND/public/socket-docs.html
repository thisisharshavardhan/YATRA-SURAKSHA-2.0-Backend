📡 Events

group:refresh EMIT

⚠️ IMPORTANT: Call this after joining/creating a group via REST API to sync your socket rooms. Without this, you won't receive location broadcasts from group members.

location:update EMIT

Send your current location. This saves to database and broadcasts to your group members.

Payload:
{
  "latitude": 28.6139,
  "longitude": 77.2090,
  "accuracy": 10,
  "speed": 5.5,
  "heading": 180,
  "altitude": 200,
  "batteryLevel": 85,
  "isCharging": true,
  "activityType": "walking"
}
location:get-group EMIT

Get current locations of all members in a group.

Payload:
{
  "groupId": "group_id_here"
}
location:stop EMIT

Stop sharing your location. Notifies group members that you went offline.

sos:trigger EMIT

⚠️ EMERGENCY! Trigger SOS alert. Notifies all group members and admins.

Payload:
{
  "location": {
    "latitude": 28.6139,
    "longitude": 77.2090
  },
  "message": "I need help!",
  "alertType": "sos"
}
sos:cancel EMIT

Cancel your active SOS alert.

alert:low-battery EMIT

Send low battery alert to group members.

Payload:
{
  "batteryLevel": 15,
  "location": {
    "latitude": 28.6139,
    "longitude": 77.2090
  }
}

📥 Incoming Events

location:updated LISTEN

Received when a group member updates their location.

Response:
{
  "userId": "user_id",
  "userName": "John Doe",
  "location": { "lat": 28.6139, "lng": 77.2090 },
  "batteryLevel": 85,
  "timestamp": "2024-01-01T12:00:00.000Z"
}
group:member-joined / group:member-left LISTEN

Received when a group member comes online or goes offline.

sos:alert LISTEN

⚠️ Received when a group member triggers SOS.

alert:battery-warning LISTEN

Received when a group member has low battery.

📡 Admin Events

admin:get-all-locations EMIT

Get current locations of all online users.

admin:get-user-location EMIT

Get location of a specific user.

admin:get-active-alerts EMIT

Get all active/unresolved alerts.

admin:resolve-alert EMIT

Resolve/close an alert.

admin:get-groups EMIT

Get all active groups.

admin:get-group-locations EMIT

Get all member locations for a specific group.

admin:subscribe-user EMIT

Subscribe to real-time updates from a specific user.

📥 Real-time Updates

admin:user-location-update LISTEN

Real-time location updates from all online users.

admin:new-alert LISTEN

⚠️ New SOS or emergency alert triggered.

admin:user-connected / admin:user-disconnected LISTEN

User connection status changes.
